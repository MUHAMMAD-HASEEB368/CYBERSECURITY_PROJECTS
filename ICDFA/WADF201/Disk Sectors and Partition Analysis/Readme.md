# PC System Fundamentals, Disk Sectors and Partition Analysis

**Course:** CIP-B101 – Basic Computer Skills for Digital Forensics  
**Lab:** Lab 01B  
**Category:** Digital Forensics | Windows System Analysis

## Overview

This practical laboratory focuses on examining computer system information, running processes, disk structures, partition layouts, and file systems.

The objective is to understand how operating system and storage-level information can be collected, interpreted, and documented for digital forensic investigations.

## Objectives

- Identify operating system and hardware specifications.
- Examine running processes and their identifiers.
- Understand disk sectors and storage capacity calculations.
- Inspect disk partitions using read-only commands.
- Understand MBR, GPT, BIOS, and UEFI concepts.
- Identify file systems and their forensic relevance.

## Tools and Environment

- Windows 11
- Windows PowerShell
- Command Prompt
- Disk Management
- DiskPart (read-only inspection commands)

## Repository Structure

- `Report/` – Public-safe practical report.
- `Readme/` – Overview of lab.


## Key Practical Work

1. System information collection.
2. Process and PID investigation.
3. Disk capacity and sector calculations.
4. Partition table inspection.
5. File system identification.
6. MBR and GPT comparison.

## Safety and Privacy

All disk inspection activities were performed using read-only commands. No partition modification, formatting, or deletion was performed.

Personal identifiers, device serial numbers, and sensitive system information have been removed from the public evidence.

## Learning Outcome

This lab provided practical experience in identifying system components, interpreting storage structures, calculating partition sizes, and documenting digital forensic evidence.
